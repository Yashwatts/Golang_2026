# Complete Go Programming Guide

A comprehensive learning repository for mastering Go (Golang) from basics to building basic applications with CLI tools and web APIs.

## Why This Repo Exists

Go is a powerful, modern programming language built for performance and simplicity. However, many developers struggle to find structured learning resources that progress from fundamentals to practical projects. This repository bridges that gap by providing:

- **Sequential learning path** - From basic syntax to advanced concurrency
- **Theory + Practice** - Concepts explained with real-world examples
- **Real Projects** - Two complete applications demonstrating different Go use cases
- **Clear explanations** - Complex topics broken down into digestible lessons

## What You Will Learn

This repository covers the complete Go programming journey:

### Fundamentals
- Introduction to Go and its ecosystem
- Setup and configuration
- Variables, constants, and data types
- User input and formatted output
- Pointers and memory management

### Intermediate Concepts
- Arrays and slices for data management
- Loops and conditional logic
- Functions and code organization
- Packages and scope rules
- Maps and structs for complex data structures

### Advanced Topics
- Goroutines and concurrency
- HTTP endpoints and web servers
- Building production-ready applications

### Real-World Projects

**1. Booking App** (CLI Based)
- Interactive command-line application
- User input validation
- Data management with slices and maps
- Function organization and packages
- Perfect for learning core Go concepts

**2. Todo App** (Web APIs Based)
- RESTful API endpoints
- HTTP server implementation
- JSON handling
- Background task processing with goroutines
- Perfect for learning web development with Go
